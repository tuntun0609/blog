Server Components 最有价值的地方，是让数据获取与渲染靠得更近，同时减少发送到浏览器的 JavaScript。

## 默认留在服务端

文章查询、排序、分页和元数据生成都不需要浏览器状态。把它们保留在服务端，可以减少边界，也避免重复请求。

## 只为交互建立边界

状态、事件处理器和浏览器 API 才需要客户端组件。边界越靠近真正的交互控件，页面其余部分就越容易缓存和流式渲染。

## 可序列化是契约

跨越服务端与客户端的 props 必须可序列化。与其绕过限制，不如重新检查组件是否真的需要进入客户端。
