# ADR 0001：博客首页采用克制排版与单层边界

- 状态：已接受
- 日期：2026-08-24
- 范围：`/blog` 首页

## 背景

博客首页同时承担作者定位、代表作策展和文章检索。原实现使用区块横线、筛选双线、卡片外框和图片内框反复划分内容；主代表作高度与标题字号也使完整文章入口落到首屏之外。结果是信息结构清楚，但边界过多、代表作过重，文字层级缺少编辑感。

## 决策

1. 保留“一主两辅”的三篇代表作，但将桌面代表作区域压缩约三分之一。
2. 移动端保留主代表作的大图，两篇辅代表作改为紧凑横向条目。
3. 继续使用原有 `Noto Sans`，通过更少的字号、字重和更稳的行高建立标题层级，不引入新的衬线字体。
4. 移除非功能性的区块横线、筛选双线、图片内框和联系区顶线。内容卡片保留单层外框，导航、输入框、分类标签及联系按钮保留必要边界。
5. 文章归档维持桌面双列、移动端单列，通过图片、网格、字号和留白建立分组。
6. 删除文章总数、分类总数和默认结果说明等重复视觉文案。动态筛选结果继续以读屏可用的实时状态存在。

## 结果

- 首屏更早暴露完整文章入口，代表作仍然承担专业能力证明。
- 页面静态边界显著减少，标题、图片和留白成为主要层级信号。
- 字体家族保持不变，调整集中在字号、字重、行高与容器宽度。
- 后续新增博客首页元素时，必须先证明其信息或交互职责，不能仅依赖边框制造结构。

## 不在本次范围

- 不改变代表作文章、分类名称、搜索行为、URL 状态或分页逻辑。
- 不重设计文章详情页。
- 不修改 `src/components/ui` 下的 shadcn/ui 原始组件。
